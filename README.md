# ELARTVIBES Demos

Öffentliche Vorschau-Websites für den Vertrieb. Jede Demo ist auf einem kostenlosen 8b-Template
(8b.com, MIT für Code, Unsplash für Fotos – Credits in den jeweiligen HTML-Dateien) aufgebaut
und mit echten, öffentlich recherchierten Daten des Zielbetriebs gebrandet.

## Struktur
- `demos/` – eine HTML-Datei pro Betrieb: `demos/<gewerk>-<betrieb>.html`
- Demo-Dateien sind One-Pager ohne Build-Schritt
- Fußzeile: „Demo erstellt von ELARTVIBES
